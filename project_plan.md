# Google Ads Marketing Performance Analytics — Project Plan

## Project Workflow

The project will follow the implementation roadmap below:

```text
Raw Data
   ↓
Profiling
   ↓
Cleaning
   ↓
Validation
   ↓
Feature Engineering
   ↓
EDA
   ↓
Campaign / Dimension Analysis
   ↓
Advanced Analysis
   ↓
Business Insights
   ↓
Power BI Dashboard
   ↓
Testing & QA
   ↓
Documentation
```

## Workflow Stages

| Stage                         | Purpose                                                                                     |
| ----------------------------- | ------------------------------------------------------------------------------------------- |
| Raw Data                      | Store and preserve the source dataset without modification                                  |
| Profiling                     | Assess structure, data types, missing values, duplicates, outliers, and data-quality issues |
| Cleaning                      | Correct or standardize identified data-quality issues                                       |
| Validation                    | Verify data integrity, transformations, and calculated metrics                              |
| Feature Engineering           | Create analytical features and derived metrics required for analysis                        |
| EDA                           | Explore distributions, relationships, patterns, and trends                                  |
| Campaign / Dimension Analysis | Analyze performance by campaign, device, location, keyword, and date                        |
| Advanced Analysis             | Perform deeper statistical and comparative analysis where appropriate                       |
| Business Insights             | Translate analytical results into actionable business findings                              |
| Power BI Dashboard            | Build the final interactive performance dashboard                                           |
| Testing & QA                  | Reconcile results, test calculations, and verify dashboard accuracy                         |
| Documentation                 | Finalize methodology, findings, recommendations, and project documentation                  |
